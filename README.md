# Quem sou eu?

Sou de Fortaleza e trabalho com desenvolvimento full stack. Gosto de sistemas que fazem sentido — quando o código reflete bem o domínio do problema, fica mais fácil de manter, de evoluir e de explicar pra qualquer pessoa da equipe.
 
Curiosidades sobre como as coisas funcionam me motivam mais do que seguir tutorial. Se tem uma abstração que não entendo, vou fundo até entender de verdade.
 
Fora do trabalho: provavelmente em espiral — uma dúvida no trabalho virou curso, que virou projeto pessoal, sempre no "como isso funciona por baixo dos panos".
