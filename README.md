## 🚀 Projeto em destaque: Aureo

Plataforma de **organização financeira pessoal**, que estou construindo ponta a ponta (API + interface web, com deploy no ar).

[![Aureo no ar](https://img.shields.io/badge/Aureo-ver%20online-1f6feb?style=for-the-badge&logo=vercel&logoColor=white)](https://aureo-front-end.vercel.app)

| | |
|---|---|
| **[AureoBackEnd](https://github.com/pedroCifoni/AureoBackEnd)** | API em **C# / .NET 10** organizada em camadas (`Api`, `Application`, `Domain`, `Infrastructure`) com projeto de testes separado. **PostgreSQL** + **Entity Framework Core**, autenticação com **JWT**, tratamento de exceções centralizado, documentação da API com **Scalar/OpenAPI** e **Dockerfile**. |
| **[AureoFrontEnd](https://github.com/pedroCifoni/AureoFrontEnd)** | **React 19** + **TypeScript** + **Vite**, **Tailwind CSS 4**, **React Router**, **Axios**. Código dividido em `pages`, `services`, `hooks`, `models` e `layouts`. Deploy na Vercel. |
